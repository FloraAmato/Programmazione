# Unita 6 - Getting Started: prima classe completa

Mette insieme attributi, costruttore e metodi in un piccolo
progetto: un'agenda con una rubrica di contatti.

## Esempi
- `Contatto.java`: rappresenta un singolo contatto.
- `Agenda.java`: contiene un array di contatti e operazioni di
  aggiunta/stampa/ricerca.
- `TestAgenda.java`: punto di avvio.
