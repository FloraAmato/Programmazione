# Unita 13 - Ereditarieta

## Argomenti
- `extends`: una classe figlia eredita campi e metodi della
  classe padre.
- Costruttore della superclasse: `super(...)`.
- Override di metodi (annotazione `@Override`).
- Modificatore `protected`.
- Java consente solo ereditarieta singola tra classi.

## Esempio: gerarchia Veicolo
- `Veicolo.java` (base)
- `Auto.java` (estende Veicolo)
- `Moto.java` (estende Veicolo)
- `TestVeicoli.java`
