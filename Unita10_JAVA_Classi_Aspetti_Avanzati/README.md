# Unita 10 - Classi: aspetti avanzati

## Argomenti
- **Membri `static`**: appartengono alla classe, non all'istanza.
- **`this`**: riferimento all'oggetto su cui il metodo e' invocato.
- **Costruttori multipli** e *constructor chaining* con `this(...)`.
- **`final`** su attributi: costanti per istanza/classe.
- Variabili di classe vs variabili di istanza.

## Esempi
- `Cerchio.java` + `TestCerchio.java`: il classico esempio della
  slide (riadattato da `Unita10_Esempio_01_Cerchio.zip`).
- `Contatore.java` + `TestContatore.java`: campo `static` per
  contare le istanze create.
- `Studente.java` + `TestStudente.java`: costruttori sovraccaricati
  che si chiamano con `this(...)`.
