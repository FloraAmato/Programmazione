# Unita 5 - Classi in Java

Sintassi della dichiarazione di classe, attributi, costruttori,
metodi getter/setter.

## Argomenti
- `class NomeClasse { ... }`
- Modificatori di visibilita: `public`, `private`, `protected`.
- Costruttore (stesso nome della classe, nessun tipo di ritorno).
- `new` per creare istanze sull'heap.
- Riferimento `this`.

## Esempi
- `Punto.java`: classe che modella un punto 2D.
- `Rettangolo.java`: classe che usa due oggetti `Punto` come vertici.
- `TestGeometria.java`: programma che istanzia e usa le classi.
