# Unita 2 - Introduzione allo Sviluppo Java

Ciclo di sviluppo: editing -> compilazione -> esecuzione.
JVM, bytecode, portabilita.

## Argomenti
- File sorgente `.java` -> compilazione con `javac` -> file `.class`
  contenente bytecode.
- La JVM esegue il bytecode su qualsiasi piattaforma (write once,
  run anywhere).
- Errori di compilazione vs errori a tempo di esecuzione.
- Lettura dell'input da tastiera con `Scanner`.

## File inclusi
- `SommaDueNumeri.java`: legge due numeri da input e stampa la somma
  (illustra `Scanner`).
- `AreaRettangolo.java`: chiede base e altezza e calcola l'area.
- `ErroreCompilazione.java.txt`: file di esempio (NON `.java`) che
  contiene errori di compilazione tipici, da copiare/correggere come
  esercizio.
