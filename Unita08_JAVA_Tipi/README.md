# Unita 8 - Tipi in Java

## Argomenti
- Tipi primitivi: `byte`, `short`, `int`, `long`, `float`, `double`,
  `char`, `boolean` (dimensioni e range).
- Tipi riferimento: classi (es. `String`).
- Costanti `final`.
- Conversioni implicite (widening) e esplicite (cast).
- Operatori aritmetici, relazionali, logici.

## Esempi
- `RangeTipi.java`: stampa min/max di ogni tipo primitivo.
- `ConversioniTipo.java`: conversioni implicite e cast esplicito,
  perdita di precisione.
- `Costanti.java`: utilizzo di `final`.
- `OperatoriAritmetici.java`: dimostra divisione intera vs reale.
