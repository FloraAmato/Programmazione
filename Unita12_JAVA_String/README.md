# Unita 12 - La classe String

## Argomenti
- `String` e' immutabile.
- Operatore `+` per concatenazione (vs `concat`).
- Confronti: `==` (riferimento) vs `equals` (contenuto),
  `equalsIgnoreCase`, `compareTo`.
- Metodi utili: `length`, `charAt`, `substring`, `indexOf`,
  `toUpperCase`, `toLowerCase`, `trim`, `replace`, `split`.
- `StringBuilder` per costruzioni efficienti.

## Esempi
- `OperazioniString.java`: panoramica dei metodi principali.
- `ConfrontiString.java`: == vs equals (insidia tipica).
- `Palindromo.java`: verifica se una stringa e' palindroma.
- `StringBuilderDemo.java`: confronto di efficienza.
