# Unita 9 - Array in Java

## Argomenti
- Dichiarazione e creazione: `int[] v = new int[10];`
- Inizializzazione esplicita: `int[] v = {1, 2, 3};`
- Lunghezza: `v.length`
- Indici: da 0 a `length - 1` (gli accessi fuori range lanciano
  `ArrayIndexOutOfBoundsException`).
- `for` classico e `for-each` (`for (int x : v)`).

## Esempi
- `MediaArray.java`: calcola la media di un array.
- `RicercaLineare.java`: cerca un elemento.
- `Inversione.java`: inverte un array in-place.
- `MinMax.java`: trova minimo e massimo.
- `EsempioForEach.java`: confronto tra `for` e `for-each`.
