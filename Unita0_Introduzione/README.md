# Unita 0 - Introduzione al Corso

Lezione introduttiva del Corso di Programmazione (Prof. Flora Amato,
Universita di Napoli Federico II).

## Argomenti
- Obiettivi del corso: programmazione orientata agli oggetti, tecniche
  avanzate, strutture dati, GUI.
- Linguaggio di riferimento: **Java**.
- Modalita d'esame, homework, libro di testo (Deitel & Deitel,
  *Programmare in Java*).

## Contenuto del progetto
Un solo file di benvenuto per verificare che la toolchain Java e
VSCode siano configurate correttamente.

## Esecuzione in VSCode
1. Aprire questa cartella in VSCode (`File -> Open Folder...`).
2. Installare l'estensione **Extension Pack for Java** (Microsoft).
3. Aprire `src/Benvenuto.java` e cliccare il bottone *Run* sopra `main`.

## Esecuzione da terminale
```bash
javac -d bin src/Benvenuto.java
java -cp bin Benvenuto
```
