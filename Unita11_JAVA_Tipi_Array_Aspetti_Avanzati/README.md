# Unita 11 - Tipi e Array: aspetti avanzati

## Argomenti
- **Array multidimensionali**: `int[][] m = new int[3][4];`
- Array di array (jagged).
- **Varargs** (`int... nums`).
- Classi wrapper (`Integer`, `Double`, ...) e autoboxing.
- Copia di array con `Arrays.copyOf` / `System.arraycopy`.
- Ordinamento con `Arrays.sort`.

## Esempi
- `Matrice.java`: somma e trasposta di una matrice.
- `JaggedArray.java`: array di array di lunghezze diverse.
- `Varargs.java`: metodo `somma(int... v)`.
- `Wrappers.java`: autoboxing/unboxing.
- `OrdinamentoArray.java`: usa `java.util.Arrays`.
